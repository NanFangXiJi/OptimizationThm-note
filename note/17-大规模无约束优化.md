当问题的维度 `n` 非常大时，传统的牛顿法等会因为计算和存储开销过大而不再适用，需要应用三种核心的高效算法：**非精确牛顿法 (Newton-CG)**、**信赖域 Newton-CG** 和 **有限记忆BFGS (L-BFGS)**。

### **1. 为什么需要新算法？大规模问题的挑战**

对于一个无约束优化问题 $\min_{x \in R^n} f(x)$，经典的牛顿法迭代公式为：
$x_{k+1} = x_k + d_k$
其中牛顿方向 $d_k$ 通过求解一个线性方程组得到：
$$
\nabla^2 f(x_k) d_k = -\nabla f(x_k)
$$
当变量维度 `n` 巨大时，这里的海森矩阵 $\nabla^2 f(x_k)$ 会变得异常庞大：
* **存储开销**：存储一个 $n \times n$ 的矩阵需要 $O(n^2)$ 的空间，当 $n=10^6$ 时，这几乎是不可能的。
* **计算开销**：精确求解上述线性方程组（如通过矩阵分解）需要 $O(n^3)$ 的计算量，这同样无法接受。

因此，我们需要既能保持牛顿法快速收敛的优点，又能避免巨大存储和计算开销的算法。

### **2. 非精确牛顿法：不求最好，但求足够好**

#### **核心思想：放宽精度要求**

既然精确求解牛顿方程组代价太大，一个自然的想法是：**我们能否只“近似”地求解它？**
答案是可以的。非精确牛顿法（Inexact Newton Method）在每一步迭代中，寻找一个方向 $p_k$，它不完全满足牛顿方程，但满足以下条件：
$$
||\nabla^2 f(x_k) p_k + \nabla f(x_k)|| \le \eta_k ||\nabla f(x_k)||
$$
其中 $0 < \eta_k < 1$ 是一个控制“不精确”程度的参数，称为**强制项 (forcing term)**。
* $\eta_k$ 越小，说明解的精度越高。
* 如果 $\eta_k = 0$，就退化为精确的牛顿法。

#### **收敛性：放松后效果如何？**

近似求解并没有破坏牛顿法的优良性质，只要我们合理地控制 $\eta_k$：

* **局部收敛性** (Theorem 7.1): 只要 $\eta_k$ 有一个小于1的上限（即 $\eta_k \le \eta < 1$），且初始点离最优点 $x^*$ 足够近，算法依然能线性收敛到 $x^*$。
* **收敛速度** (Theorem 7.2):
    * 如果 $\eta_k \to 0$，算法可以实现**超线性收敛**。
    * 如果 $\eta_k$ 下降得更快，例如 $\eta_k = O(||\nabla f_k||)$，算法可以实现**二次收敛**。

**实践中如何选取 $\eta_k$？**
为了获得快速收敛，通常让 $\eta_k$ 随着迭代的进行而减小。常用的策略有：
* **超线性收敛**: $\eta_k = \min(0.5, \sqrt{||\nabla f_k||})$
* **二次收敛**: $\eta_k = \min(0.5, ||\nabla f_k||)$

### **3. 线搜索 Newton-CG 算法**

这是非精确牛顿思想最直接的实现方式，它结合了**线搜索**和**共轭梯度法 (CG)**。

#### **算法思路**

1.  **外层循环 (牛顿法)**：在每一次迭代 $k$，我们需要求解非精确的牛顿方程来获得方向 $p_k$。
2.  **内层循环 (CG法)**：我们使用**共轭梯度法**来迭代求解线性系统 $\nabla^2 f(x_k) d = -\nabla f(x_k)$。CG法本身是一个迭代算法，非常适合只求近似解。我们让CG法一直迭代，直到满足非精确牛顿条件，或者遇到其他特殊情况。
3.  **线搜索**：找到方向 $p_k$ 后，再通过线搜索（如Armijo或Wolfe准则）找到一个合适的步长 $\alpha_k$，最终更新点 $x_{k+1} = x_k + \alpha_k p_k$。

#### **算法步骤 (Algorithm 7.1)**

**初始化**: 给定 $x_0$。
**For $k = 0, 1, 2, ...$**
1.  **设置CG的容忍度**: 定义 $\epsilon_k = \min(0.5, \sqrt{||\nabla f_k||}) ||\nabla f_k||$。这就是我们非精确条件的右侧。
2.  **调用CG法求解方向 $p_k$**:
    * **CG初始化**: 令 $z_0=0, r_0 = \nabla f_k, d_0 = -r_0$。
    * **For $j = 0, 1, 2, ...$ (CG迭代)**:
        * **负曲率检查**: 如果 $d_j^T (\nabla^2 f_k) d_j \le 0$，说明海森矩阵不是正定的，牛顿方向可能是个坏方向。此时：
            * 如果这是CG的第一步 ($j=0$)，则直接取最速下降方向 $p_k = -\nabla f_k$。
            * 否则，取当前已经计算出的方向 $p_k = z_j$ 并退出CG。
        * **CG核心步骤**:
            * $\alpha_j = r_j^T r_j / (d_j^T (\nabla^2 f_k) d_j)$
            * $z_{j+1} = z_j + \alpha_j d_j$ (更新解)
            * $r_{j+1} = r_j + \alpha_j (\nabla^2 f_k) d_j$ (更新残差)
        * **终止条件**: 如果 $||r_{j+1}|| < \epsilon_k$，说明已满足非精确条件，令 $p_k = z_{j+1}$ 并退出CG。
        * **更新CG方向**:
            * $\beta_{j+1} = r_{j+1}^T r_{j+1} / r_j^T r_j$
            * $d_{j+1} = -r_{j+1} + \beta_{j+1} d_j$
3.  **线搜索**: 找到步长 $\alpha_k$ 满足Wolfe等条件。
4.  **更新**: $x_{k+1} = x_k + \alpha_k p_k$。
**end For**

> **关键点**: Newton-CG 法巧妙地利用CG法来求解牛顿方程。CG法不仅能高效地给出近似解，还能通过“负曲率”检查来处理海森矩阵非正定的情况，从而使得算法更加稳健。

### **4. 信赖域 Newton-CG 算法**

这是另一种将非精确牛顿思想与CG法结合的强大算法，它使用信赖域框架代替了线搜索。

#### **算法思路：在“信赖圈”里用CG求解**

1.  **框架 (信赖域)**：在每一步迭代 $k$，我们定义一个以当前点 $x_k$ 为中心，半径为 $\Delta_k$ 的“信赖域”。
2.  **子问题**: 我们在这个信赖域内，求解一个二次近似模型的最小化问题，即 $\min_{||p|| \le \Delta_k} m_k(p) = f_k + \nabla f_k^T p + \frac{1}{2} p^T (\nabla^2 f_k) p$。
3.  **求解器 (CG-Steihaug)**：我们再次使用CG法来求解这个带约束的子问题。

#### **CG-Steihaug 算法 (Algorithm 7.2)**

CG-Steihaug 算法是专门为求解信赖域子问题设计的。它在标准CG的基础上增加了两个关键的“刹车”机制，以确保解始终在信赖域内。

**CG-Steihaug 迭代过程**:
在CG迭代的第 $j$ 步，我们有当前解 $z_j$ 和搜索方向 $d_j$。

1.  **刹车1：检测到负曲率**
    * 如果 $d_j^T (\nabla^2 f_k) d_j \le 0$，说明二次模型沿着 $d_j$ 方向会无限下降。我们不能再相信模型了，于是沿着这个方向一直走到信赖域的边界，将交点作为子问题的解 $p_k$ 并立即终止CG。

2.  **计算下一步**
    * 计算CG的下一步 $z_{j+1} = z_j + \alpha_j d_j$。

3.  **刹车2：超出信赖域边界**
    * 如果 $||z_{j+1}|| \ge \Delta_k$，说明这一步迈得太远，跑出了信赖域。我们不能取 $z_{j+1}$，而是找到从 $z_j$ 出发沿 $d_j$ 方向与信赖域边界的交点，将其作为解 $p_k$ 并立即终止CG。

4.  **正常终止**
    * 如果CG迭代使得残差足够小（满足 $||r_{j+1}|| < \epsilon_k$），则说明我们找到了一个在信赖域内部的很好的近似解，此时令 $p_k = z_{j+1}$ 并终止CG。

> **对比**: 线搜索Newton-CG是“先定方向，再定步长”，而信赖域Newton-CG则是“在一个圈内直接找最好的那一步”，更加稳健。CG-Steihaug通过两个巧妙的刹车机制，高效地解决了这个“圈内寻宝”的问题。

### **5. 有限记忆 BFGS (L-BFGS) 算法**

当问题规模大到连海森矩阵-向量积（$\nabla^2 f_k d_j$）都计算困难时，L-BFGS 就成了首选。它属于**拟牛顿法**，完全不计算二阶导数。

#### **核心思想：扔掉历史包袱，轻装前行**

* **BFGS回顾**: 标准的BFGS算法通过迭代来更新一个 $n \times n$ 的矩阵 $H_k$，用它来模拟真实海森矩阵的逆。但存储 $H_k$ 需要 $O(n^2)$ 空间。
* **L-BFGS的革新**: L-BFGS **不存储**完整的 $H_k$ 矩阵。它认为，构成 $H_k$ 的信息主要来自最近的几次迭代。因此，它只存储最近的 **m** 对向量 $\{s_i, y_i\}$，其中 $s_i = x_{i+1} - x_i$ (步长)，$y_i = \nabla f_{i+1} - \nabla f_i$ (梯度差)。`m` 通常是一个很小的数，比如5到20。
* **如何计算搜索方向？**: L-BFGS 利用这 `m` 对向量和 一个初始矩阵 $H_k^0$（通常是 $\gamma_k I$）来隐式地计算搜索方向 $p_k = -H_k \nabla f_k$。

#### **L-BFGS 双重循环递归 (Two-Loop Recursion)**

这是L-BFGS算法的精髓，它可以在不显式构造 $H_k$ 的情况下，高效地计算出 $H_k \nabla f_k$ 的结果。

**Algorithm 7.4: L-BFGS Two-Loop Recursion**
1.  **初始化**: $q \leftarrow \nabla f_k$
2.  **第一个循环 (向后)**:
    * **For $i = k-1, k-2, ..., k-m$**:
        * $\alpha_i \leftarrow \rho_i s_i^T q$  (其中 $\rho_i = 1/(y_i^T s_i)$)
        * $q \leftarrow q - \alpha_i y_i$
    * 这个循环结束后，`q` 相当于被一系列旧信息修正了。

3.  **中间步骤**: $r \leftarrow H_k^0 q$  (使用一个简单的初始矩阵作用在`q`上)

4.  **第二个循环 (向前)**:
    * **For $i = k-m, k-m+1, ..., k-1$**:
        * $\beta \leftarrow \rho_i y_i^T r$
        * $r \leftarrow r + s_i (\alpha_i - \beta)$
    * 这个循环把之前减掉的信息以另一种形式加了回来。

5.  **结果**: 最终得到的 `r` 就是我们想要的 $H_k \nabla f_k$。

这个过程仅涉及向量的点积和加减法，计算量为 $O(mn)$，非常高效。

#### **L-BFGS 完整算法流程 (Algorithm 7.5)**
**初始化**: 选定 $x_0$, 存储数量 $m > 0$。
**Repeat**
1.  根据最新的 `m` 组 $\{s_i, y_i\}$，用 **双重循环递归 (Algorithm 7.4)** 计算出搜索方向 $p_k = -H_k \nabla f_k$。
2.  用线搜索找到满足Wolfe条件的步长 $\alpha_k$。
3.  更新点: $x_{k+1} = x_k + \alpha_k p_k$。
4.  更新存储:
    * 计算并保存新的向量对 $s_k = x_{k+1} - x_k$ 和 $y_k = \nabla f_{k+1} - \nabla f_k$。
    * 如果存储已满 (超过 `m` 对)，则扔掉最老的那一对 $\{s_{k-m}, y_{k-m}\}$。
**Until convergence.**

> **L-BFGS 是目前解决大规模无约束优化问题最流行和最通用的方法之一**。它在计算效率和收敛性能之间取得了完美的平衡。

### **6. 附录：计算导数的有限差分法**

在很多实际问题中，我们可能无法得到梯度的解析表达式。这时，可以用有限差分来近似。
* **向前差分 (一阶精度)**:
    $$
    \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \epsilon e_i) - f(x)}{\epsilon}
    $$
* **中心差分 (二阶精度，更准确)**:
    $$
    \frac{\partial f}{\partial x_i}(x) \approx \frac{f(x + \epsilon e_i) - f(x - \epsilon e_i)}{2\epsilon}
    $$
* **海森矩阵-向量积近似 (对Newton-CG至关重要)**:
    $$
    \nabla^2 f(x) p \approx \frac{\nabla f(x + \epsilon p) - \nabla f(x)}{\epsilon}
    $$
    这个公式使得我们可以在只知道如何计算梯度的情况下，运行 Newton-CG 算法，避免了直接计算复杂的海森矩阵。
