### 1. 线性规划

线性规划是运筹学中一个极其重要的分支，它研究的是在一系列**线性**的等式或不等式约束下，如何最大化或最小化一个**线性**的目标函数。

#### 问题构成与标准型

一个线性规划问题由三部分构成：
* **决策变量 (Decision Variables)**: 我们需要决定的未知数，如生产多少件产品，记为 $x_j$。
* **目标函数 (Objective Function)**: 我们希望最大化或最小化的线性表达式，如最大化总利润 $z = c_1x_1 + ... + c_n x_n$。
* **约束条件 (Constraints)**: 决策变量需要满足的线性等式或不等式，如资源限制 $a_{i1}x_1 + ... + a_{in}x_n \le b_i$。

为了方便算法求解，我们通常将任意线性规划问题转化为**标准形式**，其特征为：
1.  **目标最小化**：若原问题是最大化 `max z`，则转化为 `min z' = -z`。
2.  **等式约束**：
    * 若约束为 $\sum a_{ij}x_j \le b_i$，则引入**松弛变量** $x_{n+i} \ge 0$，变为 $\sum a_{ij}x_j + x_{n+i} = b_i$。
    * 若约束为 $\sum a_{ij}x_j \ge b_i$，则引入**剩余变量** $x_{n+i} \ge 0$，变为 $\sum a_{ij}x_j - x_{n+i} = b_i$。
3.  **变量非负**：
    * 若变量 $x_j \le 0$，可令 $x_j' = -x_j$，其中 $x_j' \ge 0$。
    * 若变量 $x_j$ 无约束（自由变量），可令 $x_j = x_j' - x_j''$，其中 $x_j', x_j'' \ge 0$。

**标准型的矩阵形式**：
$$
\min \quad Z = c^T x \\
s.t. \quad Ax = b \\
\quad \quad x \ge 0
$$

### 2. 对偶问题

每个线性规划问题（称为**原问题 Primal Problem**）都有一个与之紧密相连的“影子”问题，称为**对偶问题 (Dual Problem)**。它们从不同的角度描述同一个经济问题，且解之间存在深刻的联系。

#### 从实例理解对偶

* **原问题（生产角度）**：一个工厂如何安排生产两种产品（甲、乙），以在有限的设备机时下，获得**最大利润**？
    * 决策变量：产品甲、乙的产量 $x_1, x_2$。
    * 目标：$max \ (2x_1 + 3x_2)$。
    * 约束：各种设备的总使用时间不能超过可用机时。

* **对偶问题（租赁角度）**：如果工厂不生产，而是将设备按小时出租，每种设备的机时应该如何定价，才能在保证“不亏本”的前提下，使总租金收入**最小**以具备市场竞争力？
    * 决策变量：设备A, B, C, D的单位时间租金 $y_1, y_2, y_3, y_4$。
    * 目标：$min \ (12y_1 + 8y_2 + 16y_3 + 12y_4)$。
    * 约束：“不亏本”原则，即出租设备去生产一件产品甲（或乙）的组合费用，不能低于自己生产所能获得的利润。

#### 如何写出任意LP的对偶问题

掌握以下对应规则，就能写出任何线性规划的对偶问题。我们以一个**最大化**的原问题为例：

| 原问题 (Primal, max) | | 对偶问题 (Dual, min) |
| :--- | :---: | :--- |
| 目标函数：`max` | $\leftrightarrow$ | 目标函数：`min` |
| 价值系数 `c` | $\leftrightarrow$ | 约束右端项 `c` |
| 约束右端项 `b` | $\leftrightarrow$ | 价值系数 `b` |
| 约束矩阵 `A` | $\leftrightarrow$ | 约束矩阵 `A^T` |
| | | |
| **约束条件** | | **变量类型** |
| 第 `i` 个约束是 `≤` | $\leftrightarrow$ | 第 `i` 个变量 `y_i ≥ 0` |
| 第 `i` 个约束是 `≥` | $\leftrightarrow$ | 第 `i` 个变量 `y_i ≤ 0` |
| **第 `i` 个约束是 `=`** | $\leftrightarrow$ | **第 `i` 个变量 `y_i` 无约束** |
| | | |
| **变量类型** | | **约束条件** |
| 第 `j` 个变量 `x_j ≥ 0` | $\leftrightarrow$ | 第 `j` 个约束是 `≥` |
| 第 `j` 个变量 `x_j ≤ 0` | $\leftrightarrow$ | 第 `j` 个约束是 `≤` |
| **第 `j` 个变量 `x_j` 无约束** | $\leftrightarrow$ | **第 `j` 个约束是 `=`** |

**对称形式（最常见）**
* **原问题 (P)**: $$\min c^T x$$ $$Ax \ge b$$ $$x \ge 0$$
* **对偶问题 (D)**: $$max \ b^T y$$ $$A^T y \le c$$$$ y \ge 0$$

#### 对偶理论的核心定理与经济含义

1.  **弱对偶定理**：任意原问题的可行解的目标值，总是不优于（大于等于，对于最小化问题）任意对偶问题的可行解的目标值。即 $c^Tx \ge b^Ty$。
2.  **强对偶定理**：如果一个问题有最优解，那么它的对偶问题也一定有最优解，并且两者最优目标值相等，即 $c^Tx^* = b^Ty^*$。
3.  **影子价格 (Shadow Price)**：对偶问题的最优解 $y_i^*$ 的经济含义非常重要，它被称为第 `i` 种资源的**影子价格**。它表示在最优方案下，第 `i` 种资源（约束右端项 $b_i$）每增加一个单位，总目标值会产生的边际收益。这可以指导企业决策，比如判断是否值得花钱购买更多资源。

### 3. 单纯形法

单纯形法由丹捷格（Dantzig）提出，是求解线性规划问题最著名、最经典的方法 。

#### 核心思想与基本概念
* **几何思想**：线性规划的可行域是一个凸多边形（或高维凸多面体）[cite: 31]。如果存在最优解，那么最优解一定可以在这个凸多面体的**顶点**上找到 [cite: 31]。单纯形法的思路就是：从一个顶点出发，沿着边移动到另一个更好的相邻顶点，不断重复，直到找到最优的顶点 。

* **代数核心——基本可行解**：
    * 在标准型 `Ax=b` 中，如果有 `m` 个约束，`n` 个变量 (`n>m`)，我们可以选出 `m` 个线性无关的列向量构成一个**基矩阵 (B)** [cite: 34]。与基矩阵对应的 `m` 个变量称为**基变量 ($x_B$)**，其余 `n-m` 个变量称为**非基变量 ($x_N$)** 。
    * 令所有非基变量 $x_N = 0$，求解 $Bx_B = b$ 得到 $x_B = B^{-1}b$。这样得到的解 $x = (x_B, x_N)$ 称为一个**基本解** 。
    * 如果这个基本解还满足非负条件 ($x_B \ge 0$)，就称之为**基本可行解 (Basic Feasible Solution, BFS)** 。
    * **关键定理**：每一个BFS在代数上都对应可行域的一个顶点 。因此，我们只需要在BFS中寻找最优解。

#### 单纯形表：算法的计算载体
为了系统地执行单纯形法的迭代步骤，我们使用一种称为**单纯形表 (Simplex Tableau)** 的表格。这个表格是整个算法的核心，它清晰地展示了当前的基本可行解、目标函数值以及判断下一步方向的所有信息。

一个标准的单纯形表（以最小化问题为例）的结构如下 ：

| | $C_j$ | $c_{1}$ | ... | $c_{n}$ | $c_{n+1}$ | ... | $c_{n+m}$ | |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **$C_{B}$** | **基 (Basis)** | **b** | **$x_{1}$** | **...** | **$x_{n}$** | **$x_{n+1}$** | **...** | **$x_{n+m}$** | **$\theta_{i}$** |
| $c_{n+1}$ | $x_{n+1}$ | $b_{1}$ | $a_{11}$ | ... | $a_{1n}$ | 1 | ... | 0 | $\theta_{1}$ |
| ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |
| $c_{n+m}$ | $x_{n+m}$ | $b_{m}$ | $a_{m1}$ | ... | $a_{mn}$ | 0 | ... | 1 | $\theta_{m}$ |
| | **检验数 $\sigma_j$** | $-Z_{0}$ | $\sigma_{1}$ | ... | $\sigma_{n}$ | $\sigma_{n+1}$ | ... | $\sigma_{n+m}$ | |

**各部分解释**：
* **第一行 ($C_j$)**: 列出所有变量（包括松弛/剩余变量）在**原始目标函数**中的系数 $c_j$ 。
* **前两列 ($C_B$, 基)**:
    * **基 (Basis)**: 当前基矩阵包含的**基变量**的名称 。
    * **$C_B$**: 这些基变量对应的目标函数系数 。
* **b 列**: 约束方程右端项的当前值，也代表了当前**基变量的取值** 。
* **中间矩阵部分 ($a_{ij}$)**: 表示当前约束条件的系数矩阵 。
* **最后一行 (检验数 $\sigma_j$)**: 这是决策行，也叫判别行。
    * `b` 列的那个值是当前目标函数值的相反数 ($-Z_0$) 。
    * 其他列的 $\sigma_j = c_j - Z_j = c_j - \sum_i (C_B)_i a_{ij}$ 。它表示当对应的非基变量 $x_j$ 从0增加1个单位时，目标函数值的变化量。
* **最后一列 ($\theta_i$)**: 用于计算**最小比值**，以确定换出变量 。

**如何从标准型构建初始单纯形表？**
当一个LP问题通过加入松弛变量化为标准型后，这些松弛变量自身就构成了一个单位矩阵，可以作为初始的基矩阵。
1.  **确定初始基**: 初始的基变量就是这些松弛变量。它们的价值系数 $c_j$ 在目标函数中通常为0。
2.  **填写表格**:
    * 将所有变量的原始价值系数填入 $C_j$ 行。
    * 将松弛变量作为初始“基”，它们的系数（通常是0）填入 $C_B$ 列。
    * 将约束方程的系数矩阵 $A$ 和右端项 $b$ 填入中间部分。
    * **计算初始检验数行**: 在这种情况下，$C_B$ 向量是零向量，所以 $Z_j=0$，因此初始检验数 $\sigma_j = c_j$ 。初始目标值 $Z_0=0$。
3.  有了这张初始表，就可以开始进行迭代了。

#### 单纯形法的计算步骤

单纯形法的每一次迭代，本质上就是从一个基本可行解（一个基）转移到另一个更好的基本可行解（换一个基），这个过程也叫**转轴操作 (Pivoting)**。

**前提：问题已化为标准型，并找到了一个初始的基本可行解。**

**Step 1: 检验是否最优**
计算每个**非基变量** $x_j$ 的**检验数 (Reduced Cost)** $\sigma_j$ 。
* **最优准则 (对于最小化问题)**：如果所有检验数 $\sigma_j \ge 0$，则当前解已是最优解，算法停止 。
* 否则，说明还有改进空间，进入下一步。

**Step 2: 确定换入变量 (Entering Variable)**
从所有 $\sigma_j < 0$ 的非基变量中，选择一个作为换入变量，通常选择**检验数最小**（最负）的那个变量 $x_j$ 。这个变量进入基后，能使目标函数值下降得最快。

**Step 3: 确定换出变量 (Leaving Variable)**
为了保证更换基之后解仍然是可行的（即所有变量非负），我们需要确定哪个当前的基变量要被换出 。
* **最小比值原则 (Minimum Ratio Test)**：对换入变量所在列的每一个正系数 $a_{ij} > 0$，计算比值 $\theta_i = b_i / a_{ij}$ 。
* 选择使得比值 $\theta$ **最小**的那个行对应的基变量作为换出变量 。这个原则保证了在引入新变量的同时，原有的基变量不会变为负数。

**Step 4: 转轴变换 (Pivoting)**
以换入变量所在列和换出变量所在行的交叉位置的元素为主元，进行高斯消元（行变换），目的是将换入变量的列变成单位向量（主元变为1，该列其他元素变为0）。这就完成了一次基的转换。

**Step 5: 循环**
回到 Step 1，用新的单纯形表重复上述过程，直至满足最优性准则。

### 4. 总结

* **线性规划 (LP)** 是一类强大的优化工具，其对偶理论揭示了优化问题背后深刻的经济联系。
* **对偶问题**提供了另一种视角，其解（影子价格）对于资源评估和决策具有重要价值。掌握其转换规则是核心技能。
* **单纯形法** 是求解LP问题的基石算法。其本质是在可行域的顶点之间进行迭代搜索，直至找到最优解。
* **核心步骤**：单纯形法的关键在于**检验数判断最优性**、**选择入基和出基变量**以及**转轴操作**。
* **两阶段法** 解决了寻找初始基本可行解的难题，使得单纯形法能够处理所有类型的线性规划问题。
